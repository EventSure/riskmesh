# Contract Setup Notes

## Program ID
The stable devnet program id is:

- `ETEEEssGKAAQEGwz3ggDcy9vzPAPtBjtb2KocdyLBMjh`

Keep these in sync before any stable redeploy:

1. `declare_id!` in `contract/programs/open_parametric/src/lib.rs`
2. `open_parametric` entry in `contract/Anchor.toml`
3. `target/idl/open_parametric.json` generated by `anchor build`

Stable redeploy:

```bash
cd contract
yarn deploy:stable
yarn verify:stable
```

If `DeclaredProgramIdMismatch (4100)` appears while calling the stable program,
the deployed binary and the declared program id are out of sync. Rebuild and
redeploy the stable program to the same `ETEEEss...` address.
